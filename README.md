# 🧠 Classificador de Dígitos Manuscritos com MNIST e Keras

Este projeto treina uma rede neural simples utilizando o dataset MNIST para reconhecer dígitos manuscritos (de 0 a 9). Além disso, ele permite testar o modelo com **imagens externas desenhadas manualmente**, como arquivos `.png` criados no Paint ou escaneados.

---

## 📦 Tecnologias Utilizadas

- Python 3.12
- TensorFlow / Keras
- NumPy
- Matplotlib
- OpenCV

---

## 🧪 Funcionalidades

- Treinamento de uma rede neural com o dataset MNIST
- Avaliação do modelo em dados de teste
- Carregamento e pré-processamento de imagens externas
- Predição de dígitos com base em imagens desenhadas à mão
- Visualização do antes e depois do pré-processamento
